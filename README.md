# Наши желания

Мобильное PWA для личного вишлиста мужа и жены. Жена добавляет желания вручную или по ссылке, муж может ставить лайки, комментировать и приватно выбирать подарок. Есть общая карта желаний, история исполненного и личный чат с фотографиями.

## Быстрый запуск

```bash
npm install
npm run dev
```

Без переменных окружения приложение запускается в демонстрационном режиме. Данные сохраняются в `localStorage`; на экране входа можно переключаться между ролями и проверять приватную логику.

## Что уже работает

- адаптивный интерфейс для iPhone, Samsung и компьютера;
- установка как PWA, offline-кеш оболочки приложения;
- желания, категории, поиск, стоимость, звёзды, фильтры и сортировка;
- ручное добавление и импорт по ссылке;
- карта желаний в виде гармоничной фотоленты;
- приватный выбор подарка мужем, лайки и общие комментарии;
- архив исполненных желаний;
- чат с текстом, эмодзи и фотографиями из галереи;
- настройки уведомлений и состояние установки приложения;
- схема Supabase с RLS, закрытым хранилищем и отдельной приватной таблицей резервов;
- автоматическая публикация на GitHub Pages.

## Подключение Supabase

1. Создайте проект на [Supabase](https://supabase.com/).
2. В Authentication → Providers включите **Anonymous Sign-Ins**.
3. Выполните SQL из `supabase/migrations/202610030001_initial.sql` в SQL Editor.
4. Разверните функцию импорта:

   ```bash
   supabase functions deploy import-link
   ```

5. Скопируйте `.env.example` в `.env.local` и укажите Project URL и publishable key.
6. Для продакшена добавьте `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` в GitHub → Settings → Secrets and variables → Actions.

Миграция создаёт таблицы пар, профилей, желаний, комментариев, лайков, приватных резервов, сообщений и push-подписок. Политики RLS разрешают доступ только участникам одной пары. У жены отсутствует политика чтения таблицы `wish_reservations`, поэтому приватный выбор мужа нельзя получить из клиентского API.

После подключения переменных окружения приложение автоматически переключается из демо-режима в облачный. Первый вход жены создаёт пару и показывает код в настройках; муж вводит этот код на своём телефоне. Для простого семейного MVP используется анонимная авторизация Supabase с отдельным постоянным идентификатором на каждом устройстве. Данные, чат и фотографии синхронизируются через Realtime и приватный Storage.

Без аккаунта Supabase нельзя выполнить последнюю проверку на двух физических телефонах. Для долгосрочной защиты от потери сессии рекомендуется следующим шагом добавить привязку анонимных аккаунтов к email или номеру телефона.

## Публикация на GitHub Pages

1. Создайте пустой публичный или приватный репозиторий GitHub.
2. Добавьте его как `origin`, сделайте commit и push в `main`.
3. В настройках репозитория откройте Pages → Source → **GitHub Actions**.
4. Workflow `.github/workflows/deploy.yml` соберёт приложение и вернёт HTTPS-ссылку вида `https://USER.github.io/REPOSITORY/`.

Vite использует относительные пути, поэтому приложение корректно работает в подпапке репозитория. Внутренняя навигация не зависит от серверных URL и не создаёт ошибок 404 после обновления страницы.

## Установка на телефон

- **iPhone:** открыть ссылку в Safari → «Поделиться» → «На экран Домой» → «Добавить».
- **Samsung:** открыть ссылку в Chrome или Samsung Internet → меню браузера → «Добавить на главный экран» или «Установить приложение».

Web Push на iPhone требует установленного на домашний экран PWA и iOS 16.4 или новее. Разрешение запрашивается только после действия пользователя в настройках.
