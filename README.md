# Наши желания

Мобильное PWA для личного вишлиста мужа и жены. Жена добавляет желания вручную или по ссылке, муж может ставить лайки, комментировать и приватно выбирать подарок. Есть общая карта желаний, история исполненного и личный чат с фотографиями.

## Быстрый запуск

```bash
npm install
npm run dev
```

Без переменных окружения приложение запускается в демонстрационном режиме. Данные сохраняются в `localStorage`; на экране входа можно переключаться между ролями и проверять приватную логику.

## Что уже работает

- адаптивный интерфейс для iPhone, Samsung и компьютера;
- установка как PWA, offline-кеш оболочки приложения;
- личные кабинеты Аллы и Стаса с входом по email и паролю, редактированием имени и аватара; аватары отображаются в общем чате и открываются крупно по нажатию;
- желания, категории, поиск, стоимость, желаемая дата, звёзды, фильтры, счётчик исполненного и виды по одной или две карточки в ряд;
- ручное добавление и расширенный импорт по ссылке: Open Graph, JSON-LD и резервный разбор карточек Avito и Золотого Яблока;
- карта желаний в виде гармоничной фотоленты;
- приватный выбор подарка мужем, лайки, общие комментарии и счётчик новых комментариев на карточке желания;
- архив исполненных желаний;
- общий календарь с режимами месяца и списка, редактируемыми событиями, розовым цветом для семьи, голубым для работы, собственными эмодзи и выбором до трёх эмодзи;
- чат с текстом, эмодзи, фотографиями из галереи, лайками и удалением своих сообщений;
- обрезка фотографий перед добавлением желания, отправкой в чат или сохранением аватара;
- серверное уменьшение и сжатие новых фотографий с долгим кешированием для быстрой повторной загрузки;
- пуш-уведомления обоим участникам о новых желаниях и сообщениях;
- подсветка новых желаний для Стаса и переход к желанию из даты исполнения в календаре;
- схема Supabase с RLS, закрытым хранилищем и отдельной приватной таблицей резервов;
- автоматическая публикация на GitHub Pages.

## Подключение Supabase

1. Создайте проект на [Supabase](https://supabase.com/).
2. В Authentication → Providers включите **Anonymous Sign-Ins**.
3. Выполните по порядку SQL-файлы из `supabase/migrations` в SQL Editor.
4. Разверните функции импорта, оптимизации изображений и пуш-уведомлений:

   ```bash
   supabase functions deploy import-link
   supabase functions deploy optimize-media
   supabase functions deploy push-notify
   ```

5. Скопируйте `.env.example` в `.env.local` и укажите Project URL и publishable key.
6. В опубликованной версии URL проекта и публичный anon key читаются из `.env.production`. Этот ключ предназначен для браузера; приватность данных обеспечивают политики RLS. Секретный `service_role` key в клиентское приложение добавлять нельзя.

Миграции создают таблицы пар, профилей, желаний, комментариев, лайков, приватных резервов, сообщений, общего календаря и push-подписок. Политики RLS разрешают доступ только участникам одной пары. У жены отсутствует политика чтения таблицы `wish_reservations`, поэтому приватный выбор мужа нельзя получить из клиентского API.

После подключения переменных окружения приложение автоматически переключается из демо-режима в облачный. Алла создаёт кабинет, подтверждает email и при первом входе создаёт пару. Код пары отображается в настройках; Стас создаёт свой кабинет и вводит этот код на своём телефоне. Данные, чат и фотографии синхронизируются через Realtime и приватный Storage. Для уже созданного анонимного профиля email и пароль можно добавить в настройках без потери данных.

## Публикация на GitHub Pages

1. Создайте пустой публичный или приватный репозиторий GitHub.
2. Добавьте его как `origin`, сделайте commit и push в `main`.
3. В настройках репозитория откройте Pages → Source → **GitHub Actions**.
4. Workflow `.github/workflows/deploy.yml` соберёт приложение и вернёт HTTPS-ссылку вида `https://USER.github.io/REPOSITORY/`.

Vite использует относительные пути, поэтому приложение корректно работает в подпапке репозитория. Внутренняя навигация не зависит от серверных URL и не создаёт ошибок 404 после обновления страницы.

## Установка на телефон

- **iPhone:** открыть ссылку в Safari → «Поделиться» → «На экран Домой» → «Добавить».
- **Samsung:** открыть ссылку в Chrome или Samsung Internet → меню браузера → «Добавить на главный экран» или «Установить приложение».

Web Push на iPhone требует установленного на домашний экран PWA и iOS 16.4 или новее. На каждом телефоне один раз откройте «Настройки» в приложении, нажмите «Пуш-уведомления» и разрешите уведомления в системном окне.
